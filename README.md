📊 Sentiment Analysis & Web Scraping Project

A Python project for collecting book and customer review data, analyzing sentiment, and generating visual reports to discover useful insights.

🚀 Project Overview

This project explores customer reviews, ratings, and sentiment patterns using Python. It generates CSV datasets, analytical reports, and charts to help understand review trends.

✨ Key Features

- Web scraping and data collection
- Customer review sentiment analysis
- Emotion detection
- Price and rating analysis
- Common words in negative reviews
- Review trend visualization
- CSV reports and PNG charts

⚙️ How to Run

1. Install Python 3.
2. Clone this repository.
3. Install the dependencies listed in "requirements.txt".
4. Run the Python script:

python scraping.py

Follow any additional setup instructions required by the script.
